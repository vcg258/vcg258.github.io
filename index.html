02 — FEATURED

Spring AI WebSocket STOMP Session+OAuth2 Flyway

world-tale-talk
LLM 인터랙티브 스토리텔링

기간: 2026.05.30 ~ 2026.07 (1개월 반) · 인원: 2명
담당: 백엔드 전체 설계·구현(Security, WebSocket, Spring AI RAG, Batch)

  • LLM이 생성하는 서사를 자유 입력/선택지로 진행하는 인터랙티브 텍스트 스토리텔링 서비스
  • 세계관 설정을 RAG(pgvector)로 임베딩해 매번 다른 전개와 맥락 유지를 동시에 확보
  • WebSocket(STOMP)으로 실시간 스토리 스트리밍을 구현
  • 세션 기반 인증에 OAuth2 소셜 로그인을 연동
트러블슈팅 STOMP 메시지 핸들러에서 @AuthenticationPrincipal로 회원 정보를 조회하면 null이 반환되는 문제 발생. WebSocket STOMP 파이프라인은 일반 MVC와 달리 인증 정보를 스레드로 옮겨주는 인터셉터가 자동 등록되지 않는 게 원인이었음. WebSocketConfig에 인증 리졸버와 SecurityContextChannelInterceptor를 직접 등록해 해결, 이후 정상적으로 인증된 사용자 정보를 받아 처리하는 것을 확인.
